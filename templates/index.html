Project Overview

MediPredict is a supervised machine learning system that predicts likely diseases from a set of patient-reported symptoms. It was built as a portfolio project demonstrating end-to-end ML development — from data generation and model training to a production-style Flask API and responsive web interface.

Tech Stack

Python 3.12 Scikit-learn Pandas NumPy Flask HTML/CSS JavaScript
